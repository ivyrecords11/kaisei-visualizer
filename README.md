# Kaisei Visualizer

Visualizer for multi-singer USTX.

## UST Subtitle Studio

A browser-based editor that converts UST and USTX lyrics into SRT or VTT subtitles:
[Open UST Subtitle Studio](https://ivyrecords11.github.io/kaisei-visualizer/)

Files are processed locally in your browser. UST/USTX projects and audio are not uploaded to a server.
